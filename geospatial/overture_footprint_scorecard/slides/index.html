Is Overture right
where you live?

Scoring every one of Philadelphia's 546,076 buildings against 8 Overture releases — on one laptop.
Overture Maps meetup · lightning talk · built with Fused Render + DuckDB
What this does

Ground truth, per building.

  • The city's own footprint layer is the reference
  • Every building gets an IoU vs. its best-matching Overture footprint shared area ÷ combined area — 1.0 is exact, 0 means Overture has nothing there
  • Repeated across 17 months of releases

Why it matters

An answer you can check.

  • Per building — not one national accuracy number
  • Runs on a laptop: no cloud bill, no tile server
  • Every one of these releases is gone from the official bucket it keeps only the two most recent — the history lives on Fused's mirror
  • Point it at any city: one bbox, one URL
How it's built

Build once, explore instantly.

  • 01Pull all 8 releases for the city bbox
  • 02DuckDB SPATIAL_JOIN — areas in EPSG:2272, not degrees
  • 03Best-overlapping match per building → one IoU
  • 04Bake all 8 scores into PMTiles as attributes
  • 05Switching release is a repaint — no refetch
