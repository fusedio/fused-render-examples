Live catalogs

Blank uses the built-in defaults. Any STAC API with a /collections endpoint works; free-text is pushed down where the catalog supports it, filtered locally otherwise. Apply checks each URL is a reachable STAC catalog first.

Download folder

Applies to every ↓ button. Paste it however you have it — quoted, backslashes, a file:// URL, ~ or %USERPROFILE% all resolve. Blank uses ~/.fused-render/downloads/ (alongside the rest of fused-render's data); a missing folder is created on first use. Remembered on this machine until you change it.

Offline index

A local snapshot of each catalog's datasets. Once built, Offline search answers instantly — bbox, text and raster/vector — with no internet, and can reach static catalogs (Maxar, Umbra) that no live search covers.

Sources build in parallel and keep running in the background — close this dialog and the header shows progress until it's done. Big sources (NASA CMR) build in resumable chunks. Find more catalogs at stacindex.org.
