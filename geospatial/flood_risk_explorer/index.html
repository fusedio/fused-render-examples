Behind the scenes

This whole app is one HTML file with a Python kernel attached — Fused Render runs flood_mask.py and overture_stats.py right next to the page. Ask Claude for a standalone HTML flood map and you get a browser sandbox: no DuckDB, no numpy, no S3. These are the actual arrays Python handed this page for the city you have open:
